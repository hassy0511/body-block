0. 準備（あそぶ前に一度）

画面は縦向き基準です。全身を写すには端末から 1.5〜3m 離れる必要があります。タブレットを縦に立てるのがおすすめ。

ホーム画面から開いた場合の更新: アプリスイッチャーから一度終了して開き直すと最新版になります。

1. ポーズでハマる！（型はめ）

タイトル → ポーズでハマる！ → 人数 → お題を見て撮影。

2. たいそうタワー（積み上げ）

タイトル → たいそうタワー → 人数 → 中央の柱に撮った姿が落ちて積み上がる。撮影6回。

3. まもって！シェルター（防御）

タイトル → まもって！シェルター → 人数 → 撮影4回で屋根を作る → 12秒のボールタイム。

4. こわしてバトル（対戦）

タイトル → こわしてバトル → ひとりで / ふたりで。カメラは中央上、写った位置が攻撃先の柱の同じ位置に落ちる。

5. いきものずかん（鑑賞）

タイトル → いきものずかん。勝ち負けなし。「なかまを よぶ」で何度でも追加。

6. コロコロゴール！（協力パズル）★今回追加

タイトル → コロコロゴール！ → 人数 → 撮影するたびにボールが転がる。かごに入れたらクリア。撮影6回。

7. あめあめキャッチ（順番に対戦）★今回追加

タイトル → あめあめキャッチ → 人数（1〜4人） → 1人ずつ撮影→アメが降る→乗った数が点数。

8. 2台モード（ゲームで使う）

カメラやく端末: pair.html を開き「カメラやく」を選ぶ。画面やく端末: ゲームのタイトル下「2だいで つなぐ」からQRを見せ合う。両方とも同じWi-Fiにつなぐこと。

つながらないとき: 2台が同じWi-Fiか確認。ルーターの「AP分離（プライバシーセパレーター）」が有効だと端末同士が通信できません。QRが読めないときは「コードを手で受け渡す」欄でメッセージアプリ経由でも接続できます。

既知の注意点

3人用のお題は現在2種類（さんにんばんざい・かいだん）。3人プレイはすぐ一周します。
